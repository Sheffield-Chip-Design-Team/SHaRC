# Website photos

Drop original photos (from the team drive, not screenshots from Instagram) into the
matching folder. Any JPG, PNG or HEIC is fine; they'll be resized and converted to
WebP before going on the site.

| Folder | What goes here | Used on the site |
|---|---|---|
| `silicon/` | Chips and boards: the ORConf board hand-over ("That's ours"), die shots under the KLA Zeta-20 / Vision Engineering microscope, dev boards | Tapeouts section, "first silicon" milestone |
| `events/` | Tiny Tapeout workshop, Semiconductor Skills Meet-Up, CCA fair stand, Microelectronics UK, Canary Wharf, Siemens Transform, Verification Futures, NEF visit, imec summer school | Events cards, photo strip under the hero |
| `community/` | Socials, lab sessions, team photos, alumni and placement students | Community/careers and Join sections |

## Naming

Name each file after the moment it shows, so it's clear where it belongs, e.g.

- `silicon/orconf-2026-board-handover.jpg`
- `events/tiny-tapeout-workshop-2026-crowd.jpg`
- `events/skills-meetup-2026-panel.jpg`
- `community/christmas-social-2025.jpg`

Optional: add a caption or photo credit in a `captions.txt` alongside the photos,
one line per file (`filename: caption`).

## Before adding a photo

Make sure everyone identifiable in it is happy to appear on a public website,
especially external guests and speakers.
